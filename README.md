# Цифровые часы с индикацией температуры, влажности и синхронизацией времени по NTP через Wi‑Fi

## Описание проекта

Устройство на базе **ESP32-C3-WROOM-02** отображает текущее время, температуру и влажность на 4-разрядном семисегментном индикаторе.

Время синхронизируется по **NTP** через Wi‑Fi. При первом включении сеть настраивается через **captive portal** (точка доступа `NTP-Clock`), учётные данные сохраняются во флэш-памяти (NVS).

При повышенной влажности/температуре включается светодиодная индикация.

## Основные функции

- отображение времени;
- синхронизация времени по NTP;
- измерение температуры и влажности;
- вывод данных на 4-разрядный семисегментный индикатор;
- настройка Wi‑Fi через captive portal (без отдельного приложения);
- ручная настройка времени и яркости кнопками;
- индикация высокой влажности светодиодом;
- тихий режим (отключение индикации).

## Используемые компоненты

### Микроконтроллер

- **ESP32-C3-WROOM-02**

### Питание

- **AMS1117-3.3** — LDO стабилизатор, 3.3 В, 1 А
- **Molex 1050171001** — разъём Micro-USB

### Датчики и индикация

- **AHT21B** — датчик температуры и влажности
- **TM1650** — драйвер 4-разрядного семисегментного индикатора
- **CC56-21SRWA** — 4-разрядный семисегментный индикатор, общий катод

### Органы управления

- 4 кнопки:
  - Reset
  - Boot / "-"
  - Select
  - "+"

## Интерфейсы

### AHT21B

- интерфейс: **I2C** (программная реализация, bit-banging)
- SDA: **IO4**
- SCL: **IO5**

### TM1650

- интерфейс: **I2C** (аппаратный)
- SDA: **IO0**
- SCL: **IO1**

## Управление

| Действие | Результат |
| --- | --- |
| Короткое нажатие **Select** | Переключение экрана: Время → Температура → Влажность |
| Длинное нажатие **Select** (≥1 с) | Вход в настройки (часы → минуты → яркость) |
| В настройках: **Select** коротко | Следующий параметр |
| В настройках: **Select** длинно | Сохранить и выйти |
| **"+" / "−"** в настройках | Изменить значение |
| **"+" и "−"** вместе 2 с | Запуск точки доступа (настройка Wi‑Fi) |
| Тройное нажатие **"−"** | Тихий режим (любая кнопка — выход) |

Подключение к Wi‑Fi: зажмите **"+" и "−"** на 2 секунды, подключитесь к сети `NTP-Clock` (пароль `12345678`), введите данные домашней сети на открывшейся странице.

## Особенности проекта

- Для исключения конфликта между **AHT21B** и **TM1650** устройства разведены на разные пары выводов микроконтроллера: датчик работает через программный I2C, драйвер индикатора — через аппаратный.
